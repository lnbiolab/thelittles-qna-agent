# LittleLabs Q&A Platform

Streamlit Q&A operations service with Naver Commerce integrations and local vector-search knowledge bases.

## Security

Do not commit `.env`, SQLite databases, customer data, or uploaded files. Copy `.env.example` to `.env` and provide runtime secrets outside Git.

## Local run

```bash
docker compose up --build
```

Production deployment and data migration require explicit approval. This repository stores application code and documentation only.
